## 2026-07-17
- **재고 위치 폐쇄 = "숨김"으로 명명** (운영자 확정): 품목별로 특정 보관위치를 화면에서 가리는 기능. "닫기"보다 "숨김"을 쓴다 — 데이터·히스토리가 남고 재고가 다시 들어오면 자동 재표시되므로 '폐쇄'보다 '가림'이 정확하고, 앱에 이미 "숨김 품목"(품목 전체 숨김)이 있어 통일하면 배울 개념이 없다. 단 층위가 다르므로(품목 전체 vs 한 품목의 한 위치) 라벨을 구분한다: 칩 상태="숨김", 동작="이 위치 숨기기", 복원="다시 표시", 재고 있을 때="남은 재고를 옮기고 숨깁니다". 서버 함수명(closeItemLocation 등)은 코드 내부용이라 UI 문구와 별개(2단계 구현 시 정합). 로직·검증·위험은 명명과 무관하게 동일. → [[domain-inventory]]
