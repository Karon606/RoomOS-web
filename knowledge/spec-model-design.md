# 규격·단가 모델 확장 설계안 (2026-07-03, 권고안 승인·시공 완료)

오류신고 3건(89f5cacc·c7cf6180·3707bf65)의 공통 뿌리 — 규격이 "숫자 하나 × 단위 하나"(specValue×specUnit)라는 가정.

## 현 모델과 이미 해결된 부분 (A단계, 2026-07-03 시공)
- Expense 품목: `specValue(숫자) × specUnit(단위) × qtyValue(수량) × qtyUnit` — 예: 2.1 L × 6개.
- **단가 기준 연동(c7cf6180)**: 지출 폼의 규격당/개당 토글 기본값이 품목의 재고 추적 단위(trackUnit)를 따름. 종량제봉투(추적단위=수량)는 개당이 기본. 치수 단위(cm·mm·m·인치) 휴리스틱은 유지.
- **행별 규격 사후 지정(3707bf65)**: 자재 상세 > 구매 내역에서 구매 행별 규격 입력·수정 가능. 자재 카드 묶음 키에 규격이 포함되므로 규격이 달라지면 카드가 자동 분리 → 단가 다른 제품의 임의 배정 해소.

## 남은 문제 (B단계 — 스키마 확장 필요, §4)
1. **다차원 규격(89f5cacc)**: 책상 1200×600×720mm, 블라인드 폭×길이 — 숫자 하나로 표현 불가.
2. **묶음 단가 기준**: "10m가 1롤" 같은 판매 단위 — 현재는 규격당/개당 2택.

## 설계 옵션
### 옵션 1 — 서술형 규격 필드 추가 (권고, 최소 침습)
- `Expense.specText String?` (예: "1200x600x720mm", "40mm용"): **표시·카드 구분에만 참여, 계산 비관여.**
- 자재 묶음 키에 specText 포함 → 사이즈 다른 제품 분리. 소모품 수학(specValue 환산)은 기존 그대로 → §4 리스크 최소.
- 마이그레이션: 컬럼 추가만(NULL 허용). 폼: 규격 입력에 "직접 서술" 토글.

### 옵션 2 — 다차원 구조화 (보류 권고)
- `spec Json?` = [{dim:'W',v:1200,u:'mm'},...]. 계산·비교·검색까지 구조화되지만 입력 UX 복잡, 소모품 환산 수학 전면 수정 — 상용화 전 단계에서 과설계 위험.

### 옵션 3 — 단가 기준 저장
- `Expense.unitBasis String?` ('spec'|'qty'|'bundle') + bundle 크기. 옵션 1과 병행 가능. 최소형: 현행 토글 값 저장만이라도(재열람 시 기준 보존).

## 세트 상품 패턴 — 주문 1 = 실물 N개 (2026-07-06, 운영자 통찰, 데이터 확증)
**하수구트랩 단가 2배 차이의 원인 = 기록 단위 차이(같은 상품)**. 데이터 확증:
- '하수구 트랩' 14,750/개 = **세트(주문단위) 단가** — 쿠팡·포근한공간 모두 동일가. 1주문 = 실물 2개 구성.
- '하수구트랩' 7,375/개 ×4행(6/15) = **낱개 단가** — 정확히 14,750÷2. 4행 합 29,500 = 2세트. 같은 상품을 낱개로 쪼개 기록한 것.
- 가설 2(무상입수 0원)는 별도 실재: 7/1 '하수구 트랩' 0원 2행(memo 무상입수) — 단가 왜곡이 아니라 별도 행.

**영수증 인식·등록 힌트 (추후 OCR 개선 시 활용)**:
1. 새 단가가 기존 이력의 **정확히 N배 또는 1/N**(특히 2배/절반)이면 세트 구성(1주문=N개) 의심 — 품명 분리로 새 품목을 만들지 말고 규격으로 흡수: qtyUnit=세트(주문단위) + specValue=N specUnit=개 + unitBasis=spec → 개당 단가 일관.
2. **무상입수(0원) 행은 단가 이력에서 제외** — getLastItemUnits 가 amount>0 행에서만 단가 역산(시공됨).

## 품목 정체성 규칙의 경계 — "언제 규격이 품명의 일부인가" (2026-07-06, 운영자 확정)
**봉투 용량은 별개 품목이 맞다**: 10L 봉투와 50L 봉투는 리터당 단가 비교가 무의미한 서로 다른 상품 —
용량이 품명에 들어가는 게 정본("종량제쓰레기봉투 50L"). 병합 대상 아님.
판별 기준: **그 규격으로 단가를 나눠 비교하는 게 상식적인가?**
- 나눠 비교함(라면 20입 vs 40입 → 개당가, 세제 1L vs 1.8L → ml당가, 하수구트랩 세트 → 개당가) = 같은 품목, 규격 필드로.
- 나눠 비교 안 함(봉투 용량별, 색상별 커버, 규격별 장판몰딩 등 용도가 갈리는 것) = 별개 품목, 품명에 포함.
주의: normalizeLabel 은 용량 표기를 지우므로 병합 후보 추천에 용량 변형이 뜰 수 있음 — 실제 병합은 항상 수동(자동 병합 금지 유지).
현재 봉투 표기 변형('(50L)' vs '100L')은 용량이 서로 달라 실파편 없음 — 표기 통일은 선택 사항.
