# 방 크기 정직 전달 — 체크리스트

계획 본문은 `docs/room-3d/plan.md`. 결정 근거는 `docs/room-3d/context-notes.md`.
각 Phase 는 판정을 통과해야 다음으로 넘어간다. 통과 못 하면 되돌아가 규격만 고친다.

## Phase 0 — 검증과 규격 확정

운영자 몫
- [ ] 도면 작성사(21세기사업정보 02-547-6100)에 원본 DWG 또는 벡터 PDF 요청
- [ ] 같은 통화에서 "치수가 구조 중심선 기준인지 마감선 기준인지" 확인
- [ ] 나머지 층 도면도 함께 요청
- [ ] 레이저 거리계·삼각대·줄자 구입 (약 15만원)
- [ ] 외창·내창·미니룸 각 1개, 총 3개 방 실측 (가로·세로·천장고·문폭·대각선 2개)
- [ ] 같은 3개 방의 침대 가로·세로 실측
- [ ] 도면 수치를 옆에 적어 대조표 작성
- [ ] 파일럿용 공실 3개를 비품만 남기고 정돈
- [ ] 방문 상담마다 "사진보다 작다" 반응 세기 시작 (기준선 4주)

개발 몫
- [ ] 360 뷰어 hfov 후보(75 안팎)와 현재값(100) 비교 화면 만들기
- [ ] Drive 에 올린 glb 가 브라우저 CORS 로 받히는지 확인 (미검증 항목)
- [ ] 안 되면 Cloudflare R2 로 결정하고 근거 기록
- [ ] 촬영 규격서 1장 확정 (plan.md 7절)
- [ ] 방 매핑표 양식 확정

판정
- [ ] 도면 대비 실측 차이 전 벽 3cm 이내면 도면을 형상 원천으로 채택
- [ ] 5cm 넘는 벽이 하나라도 있으면 도면 수치 전량 폐기, 형상만 참고
- [ ] 공개 숫자는 어느 경우든 실측만 쓴다는 원칙 기록

## Phase 1 — 정직한 2D

스키마·입력
- [ ] `Room` 실측 칸 추가 (measuredLengthCm, measuredWidthCm, ceilingHeightCm, doorWidthCm, measuredAt, measuredBy, measureMethod)
- [ ] 실측값 되돌리기용 직전값 스냅샷 칸
- [ ] `RoomPhoto` 에 shotKind, cameraMeta 추가
- [ ] 호실 관리 화면에 실측 입력 UI
- [ ] 컷별(A·B·C·D) 업로드 UI

표시 (파일럿 3방 먼저)
- [ ] 방 카드 치수 문장 ("가로 x 세로, 천장 z, 침대 놓고 남는 폭 n")
- [ ] 기준 컷 A 표시 + 170cm 실루엣 오버레이 (화면 계산, 사진에 굽지 않음)
- [ ] 광각 컷 B 에 광각 배지
- [ ] 실척 평면 카드 SVG + 1m 눈금자
- [ ] 고지 문구 노출 (plan.md 10절)
- [ ] 웹디자이너 패스 (새 UI 배포 전 필수)

공개 페이지
- [ ] `/api/public/gallery` 응답에 필드 추가 (새 함수 만들지 않음)
- [ ] `_gallery.js` 가 치수·실루엣·배지 그리기
- [ ] 4개 국어 문구

판정
- [ ] 파일럿 3방을 5~10명에게 보여 "실제와 비슷하다" 다수 확보
- [ ] 미달이면 규격만 고쳐 3방 재촬영 (23방 재촬영 금지)
- [ ] Vercel 새 함수 0 확인
- [ ] 저가 안드로이드 1대에서 공개 페이지 첫 화면 3초 이내
- [ ] 통과 후에야 나머지 20방 촬영

## Phase 2 — 치수 기반 3D 와 AR

진입 판정
- [ ] Phase 1 기준선 대비 "작다" 반응 변화 측정
- [ ] 운영자가 AR 시연 수요를 인정 (둘 중 하나도 아니면 여기서 멈춤)

구현
- [ ] `RoomLayout` 테이블 (propertyId, openings, fixtures, 텍스처)
- [ ] `Room.layoutId`, `layoutMirrored`
- [ ] 유형 배치 입력 UI (유형당 20분, 5개)
- [ ] three.js 생성기 (치수 + 배치로 방 그리기)
- [ ] glb·usdz 내보내기 (클라이언트에서, Drive 업로드)
- [ ] `RoomModelFile` + sourceHash (치수 변경 시 재생성 신호)
- [ ] `<model-viewer>` CDN 지연 로딩 뷰어
- [ ] 눈높이 150cm, 35mm 고정 화각, 170cm 인물
- [ ] AR 버튼 (Scene Viewer / Quick Look)
- [ ] 공개 에셋 감지망 명단에 추가 (knowledge/public-asset-exposure.md)

판정
- [ ] 폰 3대에서 3D 로딩 3초 이내
- [ ] AR 로 놓은 방의 침대 폭이 실측과 3cm 이내 (줄자 확인)
- [ ] 실측 치수와 모형 치수 자동 대조 감지망 통과
- [ ] 방당 1MB 이하
