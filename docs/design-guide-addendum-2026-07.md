# 통합 가이드용 추가 확정 규칙 (2026-07-11 기준)

> 용도: v1.1~v1.3 문서에 없지만 운영 중 코드로 확정된 디자인 규칙. 통합 가이드(v2.0) 제작 시 본문에 흡수할 것.

## 다크모드 (§19 보강)
- `--sand: #332619` / `--sand-2: #3D2E1F` 다크 오버라이드 — 보조 버튼 hover 표면. 라이트 sand(#f2d9b8)가 다크 글자 토큰과 짝이 안 맞아 hover 가독성 붕괴했던 사건(2026-07-11)의 산물.
- **모드 불변(고정색) 확정 목록**: 토스트 칩(bg 고정 다크 + 글자 #FBF6EF + 액션 #F2D9B8), 인쇄 문서(계약서·확인서 — 항상 라이트 종이), 스크림(rgba 검정), 구글 로고, 배치도 캔버스, 코랄 솔리드 위 #fff.
- 투명 틴트는 rgba 리터럴 대신 `color-mix(in srgb, var(--coral) N%, transparent)` — 다크에서 토큰과 함께 전환.
- 구코랄 rgba(244,98,58,…)은 리브랜딩 잔재로 전면 금지(2026-07-10 전수 제거).

## 컴포넌트 정본 범위 확정
- **Badge**: 의미색 토큰 쌍(success/warning/info/danger/coral pale) 표준 상태 배지만. 카테고리 동적 틴트, canvas 메타 칩(위치·결제수단 라벨), 오버레이(absolute), 숫자 카운터, 버튼형은 Badge 범위 밖(별도 패턴).
- **ConfirmDialog**: `choiceDialog(altLabel)` 3지선다 추가 — 취소·Esc·배경 클릭은 항상 무변경(§26.5), 제3 동작은 별도 버튼.
- **EmptyState / SkeletonRows**: 빈 상태·로딩의 유일 정본. 인라인 "불러오는 중…" 텍스트 금지(§16). 잦은 전환 라우트는 화면 골격 loading.tsx 필수.
- **AiQuotaHint**: AI 트리거 버튼 옆 정본 — "무료 AI n회 남음" + (i) 발급 안내(AiKeyGuide 단일 출처). 본인 키 영업장에는 자동 숨김.
- **InfoHint 제목은 짧게**: 팝오버 헤더가 잘리므로 명사구 위주(예: 'API 키 무료 발급').

## 문법 확정 (v1.3 이후)
- §26 인터랙션 문법(2026-07-10 성문화): 저장(즉시 vs 폼 버튼 상시 노출), 실패 통지(서버=토스트, 검증=인라인, 이중 금지), 선택 모드(명시 버튼+롱프레스 보조), undo·확인창 병행(위험도 비례), 취소 무해, 검색은 필터 스코프 내 + "다른 보기 N건" 힌트.
- 진행형 라벨 말줄임은 '…' 단일 표기('...' 금지, 2026-07-11 79곳 통일).
- 진행형 알림(해소까지 매일): 미납·재고·수령 대기에 **퇴실 경과**('경과 N일 — 처리 필요') 추가. 일정 알림(당일만)과 구분.
- 페이지 인셋: AppShell(main p-4 md:p-6) 단일 — 페이지 자체 패딩 금지(이중 패딩 5페이지 제거).
- h1 정본: text-xl font-bold + 필요 시 InfoHint. 수제 크기(22px/800 등) 금지.
