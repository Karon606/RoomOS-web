## 프롬프트 (여기부터 복사)

스테이음(고시원·원룸텔 운영 앱) **Design Guide v1.3 통합본**에 이어붙일 **§20·§21·§22·§23 네 섹션**을, 첨부한 기존 v1.3 PDF(§01~§19)와 **완전히 동일한 비주얼 시스템**으로 제작해줘. 출력은 그 PDF에 그대로 이어붙일 수 있는 **자체완결 HTML 문서**(A4 폭, PDF 내보내기용), 한국어.

### 반드시 똑같이 맞출 비주얼 문법 (첨부 PDF 기준)
- **토큰**: terracotta `#A03C2E`(강조·CTA·로고), cream `#FBF6EF`(카드/배경, 순백 금지), sand `#F2D9B8`, camel `#C8A07D`, ink `#3D2418`(텍스트, 순흑 금지), warm olive `#7A9A52`(완납/success), 의미색 `--danger/warning/info/success/deposit/reserve/inspect`(웜 단색계+블루1종), 차트 `--viz-1..8`(웜 8색).
- **타이포**: Pretendard(본문·UI·**모든 숫자 tnum**), 로고만 Plus Jakarta Sans, DM Mono 숫자 금지.
- **섹션 문법**(각 §마다 동일): 좌상단 작은 `§NN · 카테고리` 라벨 → 큰 굵은 제목 → 1~2문장 도입부(규칙·이유) → 본문 블록들. 본문 블록 종류 = ①실제 UI 목업 카드(cream 카드·테라코타 악센트) ②3열 스펙표(항목/값/비고) ③"사용 규칙" 카드 ④DO/DON'T 행(✓ 올리브 / ✕ 테라코타) ⑤색 스와치 ⑥번호 패턴 카드 ⑦치트시트 표. 좌측 3px 테라코타 막대(▌)로 소제목 표시. 카드엔 그림자 없음(보더 1px), 모달·팝오버만 그림자.
- **금지**: 순백/순흑, 블루(=--info 외), 새 hue 추가, 이모지.

### 만들 4개 섹션

**§20 · 인쇄 서류** — 첨부 `brand-guide-v1.3.md`의 §20 본문(591~753줄)을 **내용 변경 없이** 위 비주얼로 렌더. 핵심: 단일 토큰 출처 `lib/printTokens`(--p-* 색을 pdf-lib rgb + HTML hex 양쪽 정의), 도장 18×18mm, 입실료 영수증(A5·pdf-lib)·계약서(A4·puppeteer)·실거주확인서(오버레이) 3종, 실거주확인서는 브랜딩 OFF, 정산·법적 맥락 금액은 축약 금지(전체 자릿수). 목업: 영수증 A5 1장 + 도장 규격.

**§21 · 재고·리스트 컴포넌트** — 첨부 §21 본문(754~837줄)을 그대로 렌더. 핵심: `InventoryCard`(제목·메타·핵심수치·펼치기·액션), `SectionHeader`(위치 핀), `SelectionPillBar`+`PillButton`(하단 다크 알약, `--pill-bg` 라이트/다크 고정), `MergeSheet`(합치기 단일 진입·방향 고지·적용취소), 소모품/비품 두 탭 동등. 목업: 소모품 카드 + 선택 알약.

**§22 · 리스트·테이블 화면** — 호실관리·수납·고객 3종 통일. **아래는 이미 코드로 구현·배포된 확정 결정이니 그대로 정본화**(첨부 브리프의 "열린 질문"은 무시하고 이 답으로):
- **22.1 ListPageShell** — 페이지 골격 고정 순서: `헤더(제목+우측 1~2 CTA/월선택) → 풀폭 SearchBar → 1차 필터 → (정렬·표시항목) → 본문(모바일 카드 / ≥768px 테이블) → 빈상태`. 모바일·데스크탑 공통.
- **22.2 SearchBar 정본** — 좌측 돋보기 SVG + cream 배경 + rounded-sm + 우측 지우기(×) + 풀폭, 높이 ~40px(인라인 검색 예외 36px은 §13). 모바일 포함 항상 노출.
- **22.3 식별자 스타일 정본** — 호실번호·입주자명 = **ink(--warm-dark) bold + tnum**. 테라코타(coral)는 **OVERDUE(연체)·.attn에만**. (이전엔 수납만 coral이라 불일치 → ink로 통일, 연체 행만 coral + 좌측 3px 보더.)
- **22.4 1차 필터 = SegmentedControl** — 상태 빠른필터는 전 페이지 SegmentedControl(라디오·단일), '전체'가 해제. 토글 칩 금지. 다중조건 고급필터(타입·층 등)는 별도 '필터' 패널(호실관리)로 분리.
- **22.5 빈상태 = EmptyState** — 공용 `EmptyState`(아이콘+제목+설명, CTA 최대 1). 검색 결과 없음은 "다른 검색어로 시도" 설명 분기.
- **22.6 선택 모드 + 배치 액션** — '선택' 토글 → 체크박스(모바일 카드 좌측 prepend / 데스크탑 sticky 호실셀 prepend, rounded 정사각·선택 시 coral·✓) → 하단 공용 `SelectionPillBar`(unit '개'/'명'/'실') + `PillButton` → 배치 액션. **수납 일괄 처리**: 이번 달 미수 호실만 대상 자동필터 → 확인 Modal(미수 합계 tnum + DatePicker 납부일 + SegmentedControl 방법[계좌이체/현금/신용카드]) → 성공 토스트에 [적용취소](§10, 생성분 일괄 삭제).
- **22.7 sticky 테이블 정본** — `thead` sticky top-0 z-30 cream / 식별자 열(호실·입주자명) sticky-left z-20 cream / 호실셀 좌측 3px 상태색 보더 / 열 리사이즈. 768px에서 카드↔표 전환, 정렬·필터 상태 공유(§17).
- **22.8 모달 아키텍처 규칙** — **복잡한 다중탭 엔터티 상세(수납·입주자 통합)=전역 Prism 셸(EntityModal)**, **단순 추가/수정 폼(호실·고객 등록)=페이지 Modal(width sm·md·lg)**. 복잡도로 결정.
- 목업: 3페이지 × (모바일 카드 / 데스크탑 sticky 테이블 / 선택모드 + 알약 / 빈상태), 연체 행 강조 포함.

**§23 · 대시보드·위젯** — 아직 미구현이라 **네가 규범을 새로 결정**해서 정본화(첨부 `dashboard-ux-unification.md`의 감사·갭 근거). 아래 7개 정본 + 결정:
- **23.1 KpiCard 정본** — 카드 1개 = **핵심 수치 1개**(§22 원칙) + 보조 1줄. 타입 3종(강조/일반/경고)별 bg·텍스트·radius·padding 규격. (현재 7개 중 6개가 복합수치 위반 → 핵심1+보조 구조로.)
- **23.2 차트 색 매핑 정본** — 개념별 **고정 토큰 1:1**: 수입·지출·기타수익·보증금·예비비·완납·예정·미납·연체. recharts와 자체 DonutChart가 같은 개념=같은 색. raw hex(census 8종: #22c55e·#eab308·#6366f1·#dc2626·#a855f7·#f59e0b·#64748b·#d4a847) → 의미색/viz 토큰 치환.
- **23.3 위젯 카드 셸** — 공통 컨테이너(bg·border·radius·padding·헤더·진입표시), §21/§22와 정합.
- **23.4 진입(네비) 규칙** — 페이지이동=`Link` / 상세=`entityModal` / 폼=`Modal(width sm·md·lg)`. `window.location.href`·`router.push` 혼용 제거.
- **23.5 반응형 그리드** — KPI·차트·방현황의 sm/md/lg 컬럼 정본(모바일 1열 기준; 현재 KPI 항상 2열·방현황 5열 고정 → 분기).
- **23.6 빈·로딩 정본** — 위젯별 Skeleton(§16·§18, 현재 0). `dashboard/loading.tsx` 추가.
- **23.7 상태·연체 배지** — 완납/예정/미납/연체/공실 + 경과일 표기. **연체 배지 시작 기준을 명확히 결정**(예: 1일부터 "연체 D+", 7일↑ 강조 등 — §03 OVERDUE=7일 초과 정의와 정합되게 네가 결론).
- 목업: KPI 그리드(강조/일반/경고) + 차트(추이·도넛 색매핑) + 방현황 + 빈/로딩(skeleton), 모바일·데스크탑.

### 산출물 형식
1. **자체완결 HTML** 한 파일 — 기존 PDF와 동일 CSS 문법(섹션 라벨·제목·도입부·목업카드·스펙표·DO/DON'T·스와치), A4 폭, 인쇄/PDF 내보내기 OK. 외부 폰트·이미지는 인라인 또는 공개 CDN.
2. 각 §의 끝에 **사용 토큰·컴포넌트 목록** + **DO/DON'T 2~3행**.
3. (선택) 같은 내용의 **마크다운**(`docs/brand-guide-v1.3.md`에 §22·§23로 붙일 수 있게) — §21과 동일 형식.
