# 실기기 확인 목록 (운영자용, 2026-08-01 기준)

배포는 끝났고 동작은 자동 검증(타입체크·금전 회귀·빌드·감지망)을 통과했다.
아래는 **사람 눈으로만 판단할 수 있는 것들**이다. 시간 날 때 한 번에 훑으면 된다.
문제 없으면 그냥 체크만 하고, 이상하면 그 항목만 알려주면 된다.

## A. 계약서 사진 송부 (가장 중요)

- [ ] **폰에서** 고객 정보 → 계약서 파일 행 → 보내기 → **사진으로** 선택
      → 문자에 **2장이 함께** 첨부되는가. 뒷장(임의처분 동의서)이 같이 가는지가 핵심.
      (실측: 보관된 계약서는 전부 2쪽, 김태란 건은 3쪽)
- [ ] 같은 자리에서 **PDF로** 선택 → 예전처럼 1개 파일로 가는가
- [ ] **영수증**(납부 확인서 · 영수증 메뉴)에서 보내기 → 사진으로
      → **1장만** 가고 파일명에 `_1` 같은 번호가 **안 붙는가**

## B. 인쇄

- [ ] **맥에서** 계약서 파일 행의 **보기** → 새 탭에 PDF가 뜨는가
      (파일이 다운로드만 되면 알려줄 것 — 서버 설정을 바꿔야 한다)
- [ ] 그 탭에서 `Cmd + P` 로 인쇄되는가
- [ ] **폰에서** 보내기 → 공유 시트 안에 **프린트** 항목이 있는가

## C. 계약서 파일 화면

- [ ] 고객 정보를 열었을 때 **계약서 파일이 계약 정보 바로 아래**에 오는가. 그 위치가 쓰기 편한가
- [ ] 모달 **하단 버튼이 셋**으로 줄었는데(삭제·실거주 확인서·입실료 납부 확인서·수정)
      좁은 화면에서 줄바꿈이 어색하지 않은가
- [ ] 고객 정보 **수정** 화면의 계약서 파일이 보기 화면과 같아졌는가
      (수정 중에는 '서명 요청 보내기'만 일부러 안 보인다)
- [ ] 계약서가 없는 사람 / 서명 요청만 보낸 사람 / 파일이 있는 사람을 각각 열었을 때
      **진한 버튼이 상황에 맞게 하나씩** 바뀌는가

## D. 용어

- [ ] 계약서·실거주 확인서·납부 확인서 세 메뉴에서 같은 버튼이 **같은 이름**으로 불리는가
- [ ] '다시 작성'(예전 '재발급')을 눌렀을 때 기대와 맞는가

## E. 이전 작업 (F페이즈, 미확인 상태로 남아 있던 것)

- [ ] 월 전환 시 상단 진행바가 도는가
- [ ] 서류 화면으로 넘어갈 때 무반응 구간이 없는가
- [ ] 도면 화면 하단이 잘리지 않는가
- [ ] 큰 글자 설정에서 확인창 버튼이 화면 밖으로 나가지 않는가

---

이상이 있으면 항목 번호만 알려주면 된다. 원인 분석과 수정은 그쪽에서 한다.
